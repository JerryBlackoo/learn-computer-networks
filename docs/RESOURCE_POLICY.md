# 资源与引用政策

## 原创与边界

- 本仓库全部**中文讲义、实验说明、作业 API 命名、仿真代码与测试**均为原创教学材料。
- **不得**复制或改写任何课程的实验 PDF、评分 rubric、官方 solution、或第三方仓库中的实现代码（包括但不限于 CS144、教材配套实验包等）。
- 允许在讲义中**概念层面**讨论分层、滑动窗口、距离向量等与本科网课一致的**主题**，但实验接口与场景设计必须独立。

## 外链规则

- **唯一**允许放置官方/规范 URL 的位置：`sources/catalog.toml`。
- `docs/`、`modules/*/README.md` 与代码注释中**不粘贴**外部课程主页、作业下载链接或非规范文档 URL。
- 需要引用协议语义时，在讲义中写 RFC 编号与中文释义，读者通过 `catalog.toml` 自行打开官方文本。

## 安全与用途

- 本路径仅用于**防御性、教育性**的协议实现与分析（本地仿真、合成 trace、本机 stub 服务）。
- **禁止**在本仓库中收录：漏洞利用工具链、未授权扫描脚本、恶意样本、或面向真实网络的攻击性 PoC。
- 抓包与测量实验仅使用**仓库内合成 fixture** 或学生在本机生成的合法流量。

## 证据标签

各模块 `module.meta.toml` 中的 `evidence` 字段含义：

| 标签 | 含义 |
|------|------|
| `host-verified` | 在本机 `make verify` 中由 pytest 自动执行并通过 |
| `not-run` | 需人工环境（如多机、真实网卡）或未纳入 CI 的检查 |

不得将 `not-run` 项目宣传为已自动验证。

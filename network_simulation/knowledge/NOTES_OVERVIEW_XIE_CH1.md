# 谢希仁第 1 章概述 · 精读笔记（答案 FAQ）

> 来源：答案可提取文本（问题 1-1～1-20 等）+ 王道第 1 章书签。教材扫描页以答案概念为准交叉。

## 核心联系（全五层的“总开关”）

1. **internet vs Internet**；网络的网络。  
2. **面向连接 ≠ 电路交换**：分组交换也可面向连接（X.25 等）；IP 无连接。  
3. **各层可混用连接语义**：邮件→TCP（连接）→IP（无连接）→PPP（连接）。  
4. **E2E 可靠**：IP 尽力而为；可靠主要由运输层/端系统负责（问题 1-14）。  
5. **五层模型**：应用 / 运输 / 网络 / 数据链路 / 物理（与 TCP/IP 四层对照见总览）。

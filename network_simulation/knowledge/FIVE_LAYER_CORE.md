# 五层计算机网络：知识点系统梳理与关联

> 资料依据：`books/` 中谢希仁《计算机网络》第 8 版（书签/章节）、配套答案（可提取文本的 FAQ）、期末试卷、王道《计算机网络》（完整书签大纲）。  
> 范围：物理层 → 数据链路层 → 网络层 → 运输层 → 应用层（与谢希仁五层模型 / 王道考研主干对齐）。  
> 实现映射：同目录旁 `network_simulation/cpp/` 用 C/C++ 仿真各层核心数据结构与算法。

## 0. 总览：分层、服务与端到端

### 0.1 三套模型如何对应

| 视角 | 层划分 | 本仓库仿真对应 |
|------|--------|----------------|
| OSI | 7 层（含表示/会话） | 不单独实现表示/会话 |
| TCP/IP 经典四层 | 应用 / 运输 / 网际 / 网络接口 | 应用+运输+网络；接口≈链路+物理 |
| 谢希仁五层 | 应用 / 运输 / 网络 / 数据链路 / 物理 | **本仿真采用的分层** |

### 0.2 跨层核心联系（谢希仁答案强调）

1. **面向连接 ≠ 电路交换**：电路交换一定面向连接；分组交换可以面向连接（X.25/帧中继/ATM）也可以无连接（IP）。
2. **各层可独立选择连接语义**：例如邮件用面向连接的 TCP，TCP 跑在无连接的 IP 上，IP 又可跑在面向连接的 PPP 上。
3. **端到端可靠性（E2E）**：IP 故意做成“尽力而为”；可靠交付主要由运输层 TCP（及应用）负责。链路层 CRC 只做检错丢弃，不承诺端到端可靠（新版教材观点）。
4. **PDU 命名链**：应用报文 → TCP 段 / UDP 数据报 → IP 数据报（分组） → 帧 → 比特。

### 0.3 期末试卷考点如何挂到五层

| 试卷题意 | 涉及层 | 关联知识点 |
|----------|--------|------------|
| ARP 请求/欺骗、MAC | 链路 + 网络 | ARP 缓存、广播域、VLAN |
| 浏览器访问域名 | 应用→运输→网络→链路 | DNS、TCP 握手、HTTP、封装 |
| TCP 握手/释放、MSS、吞吐量、Seq/Ack | 运输 | 三次握手、滑动窗口、字节流序号 |
| 子网划分、静态路由、NAT | 网络 | CIDR、LPM、地址转换 |
| Ping、端口 53、MAC 改写 | 网络+链路+应用 | ICMP/DNS、逐跳改 MAC 不改 IP（除非 NAT） |

## 1. 物理层

### 1.1 王道大纲知识点

- **通信基础**：数据/信号/码元；信源/信道/信宿；速率、波特、带宽。
- **极限容量**：奈奎斯特定理（理想无噪信道最大码元速率）；香农定理（有噪信道最大数据率）。
- **编码与调制**：数字→数字编码；模拟→数字；数字→模拟；模拟→模拟。
- **传输介质**：双绞线、同轴、光纤、无线；物理层接口特性。
- **设备**：中继器、集线器（放大/再生，不识别帧）。

### 1.2 谢希仁答案中的关键辨析

- 传输媒体 **不是** 物理层本身：媒体是通路，物理层是**如何在媒体上传输比特**的规程。
- 奈氏准则管“能传多快码元”；香农管“在噪声下能可靠传多少比特”。
- 同步/异步、位同步/帧同步：物理层关心比特对齐；帧边界属链路层。

### 1.3 与上层联系

- 物理层交付的是**不可靠比特流**；差错检测从链路层 CRC 开始。
- 集线器扩大冲突域；交换机（链路层）分割冲突域——期末 VLAN/交换机题的根基。

### 1.4 仿真映射

- `PhyLink`：比特/字节流信道，可注入误码、延迟；不解析帧结构。

## 2. 数据链路层

### 2.1 王道大纲知识点

| 主题 | 要点 |
|------|------|
| 功能 | 成帧、透明传输、差错检测、流量控制、链路管理 |
| 组帧 | 字符计数、字节填充、零比特填充、违规编码 |
| 差错控制 | 奇偶、**CRC**；海明码等纠错 |
| 可靠传输 | 停等、**滑动窗口**、GBN、SR |
| MAC | TDM/FDM/WDM/CDM；ALOHA、CSMA、CSMA/CD、令牌 |
| 局域网 | 以太网帧、MAC 地址、CSMA/CD、VLAN、802.11/CSMA/CA |
| WAN | PPP |
| 设备 | 网桥、交换机自学习 |

### 2.2 谢希仁答案中的关键辨析

- **新版观点**：以太网/PPP 链路层**不**向网络层承诺无差错链路；CRC 错则丢帧。
- 仍要做 CRC：避免把坏帧交给上层浪费资源（“检错丢弃”≠“可靠传输”）。
- 可靠传输算法（停等/GBN/SR）可在链路层讲原理，现代局域网常把可靠交给 TCP。

### 2.3 与网络层交叉：ARP

- ARP 在“网络层地址 ↔ 链路层地址”之间解析，报文通常封装在以太网帧中广播。
- 期末题：ARP 欺骗利用“收到应答不校验是否发过请求”的缓存弱点。

### 2.4 仿真映射

- `EthernetFrame` + `crc32`：成帧与 FCS。
- `SlidingWindow`（停等/GBN）：序号、ACK、重传。
- `ArpTable` / `ArpProtocol`：请求应答与缓存。

## 3. 网络层

### 3.1 王道大纲知识点

| 主题 | 要点 |
|------|------|
| 功能 | 异构互连、路由与转发、虚电路 vs 数据报、拥塞概念、SDN 简介 |
| IPv4 | 首部、分片、分类地址、子网、**CIDR**、路由聚合、NAT、转发过程 |
| 辅助协议 | **ARP**、DHCP、ICMP |
| IPv6 | 特点、首部、地址、过渡 |
| 路由 | 静态/动态；**DV / LS**；RIP、OSPF、BGP |
| 设备 | 冲突域/广播域；路由器组成；路由表与转发 |

### 3.2 谢希仁答案中的关键辨析

- 路由器按**网络前缀**转发，只存“下一跳”，好处是表规模可控、路径可动态变化。
- **最长前缀匹配（LPM）**：目的地址与多条前缀（如 `11.0.0.0/8`、`11.1.0.0/16`、`11.1.2.0/24`）比较时，选前缀最长且匹配者（答案习题 `<4-49>` 等）。
- IP 广播 ≠ 链路广播：IP 广播需路由器按策略处理；链路广播不出网段。
- 分片：因各链路 MTU 不同；单一广域网内部可约定统一分组大小。
- 链路层 PPP/CSMA/CD **不**向网络层承诺可靠链路（新版相对 OSI/HDLC 的提法变化，见答案问题 3-1）。

### 3.3 与运输层/应用层联系

- IP 提供主机到主机；TCP/UDP 提供进程到进程（端口）。
- Ping（ICMP）与 DNS（UDP/53）是期末抓包题常见载荷。
- NAT：改写 IP/端口，使私网可达公网——试卷问“是否做了 NAT”。

### 3.4 仿真映射

- `Ipv4Header` + `internet_checksum`。
- `RouteTable::longest_prefix_match`（LPM）。
- `Arp` 与 IP 发送路径绑定：缺缓存则先 ARP 再发。

## 4. 运输层

### 4.1 王道大纲知识点

| 主题 | 要点 |
|------|------|
| 服务 | 进程通信、复用/分用、检错、面向连接 vs 无连接 |
| 寻址 | 端口、套接字 |
| UDP | 首部、伪首部校验和 |
| TCP | 特点、段格式、**连接管理**、可靠传输、流量控制、**拥塞控制** |

TCP 拥塞控制四机制：**慢开始、拥塞避免、快重传、快恢复**。

### 4.2 谢希仁答案中的关键辨析

- TCP 面向连接、端到端；IP 无连接、逐跳——可靠由 TCP 补齐。
- 链路层滑动窗口管相邻节点；TCP 滑动窗口管端到端字节流。
- 即使链路全可靠，TCP 仍必要：端系统缓存/进程崩溃等仍可能丢数据（E2E 论证）。
- 初始序号不能固定：避免旧连接段与新连接混淆。

### 4.3 与应用层联系

- HTTP 默认 TCP/80 或 443；DNS 默认 UDP/53（也可 TCP）。
- 期末：三次握手、MSS 协商、Seq/Ack 推算、应用字节数统计。

### 4.4 仿真映射

- `UdpDatagram` + 校验和。
- `TcpPcb`：三次握手/四次挥手状态机、序号确认、重传。
- `CongestionControl`：cwnd、ssthresh、慢开始/拥塞避免/快重传。

## 5. 应用层

### 5.1 王道大纲知识点

- 网络应用模型：C/S、P2P。
- **DNS**：层次域名、根/TLD/权威/本地服务器、递归与迭代解析。
- FTP：控制连接与数据连接。
- 电子邮件：SMTP、POP3/IMAP、MIME。
- **WWW/HTTP**：报文结构、无状态、代理、HTTP/1.1 与 HTTP/2 要点。

### 5.2 谢希仁答案中的关键辨析

- “两台计算机通信”实质是**应用进程**通信。
- ARP 解析同网段 MAC；DNS 解析全球主机名→IP——相似在“名字/地址映射”，范围与协议层不同。
- HTTP 特点：简单、灵活、无状态；1.1 持久连接等；2 多路复用等。

### 5.3 仿真映射

- `DnsResolver`：本地域名表查询。
- `HttpClient` / `HttpServer`：请求行/状态行极简解析。
- 端到端：`Host` 上 HTTP → TCP → IP → Ethernet → Phy → 对端解封装。

## 6. 知识点关联图（封装路径）

```
应用数据 (HTTP 请求体/DNS 查询)
    │ 应用层加上应用报文语义
    ▼
TCP 段 / UDP 数据报     ← 端口、序号/ACK、校验和、拥塞窗口
    │ 运输层交给网络层
    ▼
IP 数据报               ← 源/目的 IP、TTL、首部校验和；查路由表 LPM
    │ 若下一跳 MAC 未知 → ARP
    ▼
以太网帧               ← 源/目的 MAC、类型、CRC
    │
    ▼
物理比特流             ← 信道误码/延迟/丢包注入
```

**解封装逆序**：Phy → 校验 CRC → 解以太网 → 解 IP → 解 TCP/UDP → 应用处理。

# 模块 08：NAT 与中间盒直觉

## 学习目标

- `ZhongjianHe` 维护 **NAPT** 映射：内网 `(ip, port)` ↔ 公网 `(gongwang_ip, 分配端口)`。
- 理解**出向创建映射、入向查表转发**的不对称性。

## 核心概念

- **出向 `chu_kou`**：首次访问分配新公网端口并双向登记；重复调用应返回**稳定**映射。
- **入向 `ru_kou`**：仅凭公网端口反查内网五元组的一部分（教学简化）。

## 不变量

- 不同内网主机即使使用相同内网端口，也应映射到不同公网端口（测试覆盖）。
- 端口从 `xiayige_duankou` 单调递增（未模拟耗尽与回收）。

## 常见失败模式

| 现象 | 原因 |
|------|------|
| 入向失败 | 未写入 `ru_biao` |
| 映射抖动 | 每次出向都分配新端口 |
| 误以为 ALG | 本模块不解析 FTP/SIP 载荷 |

## 明确非目标

- 无 NAT 穿透、无防火墙状态检测、无运营商 CGNAT 政策。

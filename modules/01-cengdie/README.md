# 模块 01：分层与端到端论证

## 学习目标

- 理解**封装/解封装**如何在相邻层之间传递 PDU，以及「层」只是组织复杂性的视角。
- 用**端到端论证**解释：哪些语义必须在通信端点实现，中间节点应尽量保持无状态或简单转发。
- 区分**不变量**（层间接口契约）与**实现细节**（某一层的具体算法）。

## 核心概念

| 概念 | 在本模块中的含义 |
|------|------------------|
| PDU / SDU | 每层有自己的协议数据单元；上层 PDU 作为下层 SDU 被封装 |
| 封装栈 | 自底向上逐层加头；解封装时若头不匹配应失败（教学上显式报错） |
| 端点语义 | 可靠性、完整性校验、会话状态等通常属于端点或端点附近 |

## 不变量

- 封装顺序与 `cengxu` 声明一致；解封装必须逆序剥离且前缀可验证。
- `DuanDaoDuanLunzheng` 登记的语义应被视作「必须在端点实现」的清单，而非路由器职责。

## 常见失败模式

- **层序错误**：解封装时层名与载荷前缀不一致 → 应拒绝继续，避免静默错解。
- **中间盒越权**：在链路层试图实现本应在传输层完成的重传 → 破坏端到端语义（后续模块会对比）。

## 结合 IP 转发与 ARP 大题理解分层

读完本模块，可到模块 03 完成[逐跳转发综合题](../03-ip-zhuanfa/exercises/01-ip-datagram-forwarding.md)和[ARP 综合题](../03-ip-zhuanfa/exercises/02-arp-resolution.md)。实际协议发送时，应用数据逐层经过传输层、IP 层和链路层封装；中间设备承担的工作不同：

| 设备或协议 | 在这两题中的职责 |
|---|---|
| 集线器 | 重复物理信号，不查询 MAC 或 IP |
| 普通二层交换机 | 按 VLAN 和目的 MAC 转发或泛洪，透明转发不改 IP TTL |
| 路由器 | 根据目的 IP 查路由，更新 TTL，并为下一条链路重新封装 |
| ARP | 在当前链路解析下一跳 IPv4 对应的 MAC；直接封装于以太网，载荷不是 IP 数据报 |
| IPsec | 提供 IP 层安全机制，与 TLS 所在层次不同 |

重点对照：“H1 → H7”中端到端源/目的 IP 保持，而每段帧的源/目的 MAC 变化。MAC 变化来自路由器跨链路重新封装，不能误写成每经过一台交换机也更换地址。

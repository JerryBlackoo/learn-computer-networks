## 核心概念

- **前缀长度**：`ZhuanfaXiang.changdu` 与 `mudi_wang` 的掩码长度一致，用于比较「谁更长」。
- **匹配规则**：目的 IP 落入某前缀即候选；在候选中取**最长**前缀；无匹配返回 `None`。
- **默认路由**：`0.0.0.0/0` 的 `changdu` 为 0，仅在没有更具体前缀时胜出。

## 边界用例（实验与测试会覆盖）

- 10.1.2.3 同时匹配 /8 与 /16 → 应选 /16 下一跳。
- 192.168.1.5/32 与 192.168.0.0/16 并存 → /32 主机路由优先。
- 表中无覆盖前缀 → `None`（无默认路由时等价于丢弃，教学上可讨论黑洞路由）。

## 不变量

- `changdu` 必须与 `ip_network(mudi_wang)` 的真实前缀长度一致（由出题方保证；实现只比较 `changdu` 字段）。

## 常见失败模式

- 用字符串比较 IP 而非 `ipaddress` 语义。
- 平局时随意选择：本仓库约定按**更大 changdu** 获胜；同长时**先出现在表中的项**不被后者覆盖（实现使用 `>` 而非 `>=`）。

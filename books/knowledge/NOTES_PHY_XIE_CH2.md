## 核心命题：传输媒体 ≠ 物理层

物理层考虑的是**怎样在传输媒体上传输比特流**，不是媒体本身。作用是尽可能屏蔽媒体与通信手段差异，使数据链路层感觉不到这些差异。

物理层接口四特性：

| 特性 | 含义 |
|------|------|
| 机械 | 接插件形状、尺寸、引脚、固定装置 |
| 电气 | 线上电压范围 |
| 功能 | 某一电平电压的意义 |
| 过程 | 事件出现的顺序 |

机内多并行传输，线路上一般为**串行**比特流 → 物理层还完成传输方式转换。

## 数据通信系统模型

源系统（源点 + 发送器）→ 传输系统 → 目的系统（接收器 + 终点）。

术语链：**消息 → 数据 → 信号**

- 模拟信号：参数连续  
- 数字信号：参数离散；时域基本波形称**码元**

## 信道与双工

信道 ≠ 电路；信道常指某一方向的传送媒体。一条电路往往含发送+接收信道。

- 单向（单工）  
- 双向交替（半双工）  
- 双向同时（全双工）— 效率最高  

ITU-T 避免混用口语“单工电台”等说法。

## 调制与编码

- **基带调制/编码**：数字→另一种数字波形（NRZ、RZ、曼彻斯特、差分曼彻斯特）  
- **带通调制**：用载波搬移到较高频段（AM/FM/PM；更高速率用 QAM 等）

曼彻斯特：有自同步能力；不归零制无自同步能力。

## 信道极限容量（OCR p57–p58）

限制码元速率的因素：① 信道可通过的频率范围（码间串扰）→ **奈氏准则**；② 噪声 → **香农公式**。

- **奈氏准则**（理想无噪、带宽 \(W\) Hz 的低通信道）：最高码元速率 \(= 2W\) 码元/秒。例：\(W=4000\) Hz → 8000 码元/s。若每码元携带 \(\log_2 M\) bit，则最高数据率 \(C=2W\log_2 M\) bit/s。
- **信噪比**：\(\mathrm{SNR_{dB}}=10\log_{10}(S/N)\)。例：\(S/N=1000\) → 30 dB。
- **香农公式**：\(C = W\log_2(1+S/N)\) bit/s。只要速率低于 \(C\)，理论上存在无差错传输方法（但不给出构造）。

提高速率路径：在码元速率已达奈氏上限时，让**每码元携带更多比特**（多元调制，如 8-PSK、QAM），但仍受香农上限约束。

## 传输媒体（提要）

导引型（双绞线/同轴/光纤）与非导引型（无线）。双绞线：UTP/STP、EIA/TIA-568 类别与带宽（3/5/5e/6/6A…）。**媒体本身不属于物理层协议范围**，但物理层必须适配其上的电气与过程特性。

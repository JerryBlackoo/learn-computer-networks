# 谢希仁第 6 章应用层 · 精读笔记

> 来源：教材 OCR（约 p271+）+ 答案 FAQ 6-x + 王道第 6 章 + 期末 DNS/HTTP 访问路径。

## 应用层协议定义什么？

- 报文类型（请求/响应）  
- 语法（字段）  
- 语义  
- 何时发送/如何响应的规则  

应用层协议 ≠ 整个网络应用（HTTP 只是 Web 应用的一部分）。

## C/S 与进程通信（答案）

- **6-1**：“两台计算机通信”实质是**应用进程**通信。  
- **6-9**：ARP 与 DNS 都做“名字/地址映射”，但 ARP 在同网段 IP↔MAC，DNS 在全球主机名↔IP，层次与协议层不同。

## DNS

层次：根 / TLD / 权威 / 本地；递归与迭代；主机缓存与定期刷新（OCR）。期末：解析谁、结果 IP、服务器 IP。

## FTP（OCR ≈p280）

控制连接 + 数据连接；屏蔽异构文件系统；早期互联网流量大户。TFTP 基于 UDP。另有联机共享类（NFS）与“整文件复制”类对比。

## HTTP

无状态；请求行/状态行；1.0/1.1 持久连接等。期末：浏览器访问域名串联 DNS→TCP→HTTP。

## 仿真映射

- `DnsResolver`、`HttpRequest`/`HttpResponse`  
- e2e：`Host` 上 DNS(UDP/53) + TCP/80 + HTTP GET  

## 与期末试卷故事线

`PC 浏览器 → DNS → TCP 握手 → HTTP → 以太网/ARP → 路由/NAT`  
正是五层封装路径的完整实例（见 `FIVE_LAYER_CORE.md` §6）。
